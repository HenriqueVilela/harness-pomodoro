# Sinais de estado da sessão

> Ajuste conforme for ensinando — o layout do Instagram muda com frequência.

## Logado
- Barra lateral/inferior com: Página inicial, Pesquisa, Explorar, Reels,
  Mensagens, Notificações, Criar, Perfil
- Feed com stories no topo
- URL `instagram.com/` sem `/accounts/login`

## Deslogado
- Campos "Telefone, nome de usuário ou email" e "Senha"
- Botão "Entrar" / "Log in"
- URL contendo `/accounts/login`
- Link "Cadastre-se" / "Sign up"

## Desafio de segurança
- URL contendo `/challenge/` ou `/two_factor/`
- Textos: "Digite o código", "Confirme que é você", "Suspicious login"

## Diálogos pós-login
- "Salvar suas informações de login?" → Agora não
- "Ativar notificações" → Agora não
